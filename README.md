# Crazy Hen Run

Native SwiftUI app for iOS and iPadOS. Open `CrazyHenRun.xcodeproj` and run the **CrazyHenRun** scheme.

```bash
xcodebuild -project CrazyHenRun.xcodeproj -scheme CrazyHenRun \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build
```

Codemagic builds this Xcode project directly. There is no Flutter, CocoaPods, or Dart on this branch.
